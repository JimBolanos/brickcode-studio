# RCX firmware

Copies of the official RCX firmware files, as shipped in the nqc project
(https://github.com/jverne/nqc/tree/master/firmware), so the install works offline.

- `firm0328.lgo` - RCX 2.0 firmware (target RCX2, the default)
- `firm0309.lgo` - original RCX 1.0 firmware (target RCX)

Send one from BrickCode Studio (gear button, Brick utilities) or run:
`nqc -Susb -firmware firm0328.lgo`

The firmware is LEGO's; it is redistributed here the same way nqc does.
